## 📡 API 接口文档

### 基础地址
```
http://localhost:3001/api/region
```

### 接口列表

#### 1. 获取省级列表
```
GET /provinces
```

**响应示例**:
```json
{
  "success": true,
  "data": [
    {
      "code": "130000000000",
      "name": "河北省"
    }
  ],
  "total": 30
}
```

#### 2. 获取市级列表
```
GET /cities/:provinceCode
```

**参数**:
- `provinceCode`: 省级代码，如 `130000000000`

#### 3. 获取县级列表
```
GET /counties/:cityCode
```

**参数**:
- `cityCode`: 市级代码

#### 4. 获取乡镇级列表
```
GET /towns/:countyCode
```

**参数**:
- `countyCode`: 县级代码

#### 5. 获取村级列表
```
GET /villages/:townCode
```

**参数**:
- `townCode`: 乡镇级代码

#### 6. 搜索行政区
```
GET /search?keyword=xxx&level=1
```

**参数**:
- `keyword`: 搜索关键词
- `level`: 可选，限制搜索级别（1-5）

#### 7. 获取完整路径
```
GET /path/:code
```

**参数**:
- `code`: 行政区代码

**响应示例**:
```json
{
  "success": true,
  "data": {
    "province": { "code": "130000000000", "name": "河北省" },
    "city": { "code": "130100000000", "name": "石家庄市" },
    "county": { "code": "130102000000", "name": "长安区" },
    "town": null,
    "village": null
  }
}
```

## 🔧 数据关联规则

### pcode 字段
数据库中使用 `pcode` 字段来关联父级行政区：

- **市级数据**: `pcode` = 对应的省级 `code`
- **县级数据**: `pcode` = 对应的市级 `code`
- **乡镇级数据**: `pcode` = 对应的县级 `code`
- **村级数据**: `pcode` = 对应的乡镇级 `code`

### 查询示例

获取河北省（130000000000）下的所有城市：
```sql
SELECT code, name 
FROM china_area_2024 
WHERE level = 2 AND pcode = '130000000000'
ORDER BY code;
```

## 🐛 故障排查

### 后端连接失败
1. 检查 PostgreSQL 服务是否运行
2. 检查防火墙是否允许 5432 端口
3. 验证数据库连接信息是否正确

### 前端无法获取数据
1. 确认后端服务器已启动（`http://localhost:3001`）
2. 检查浏览器控制台的网络请求
3. 检查 CORS 配置

### 数据显示不完整
1. 检查数据库表中的 `pcode` 字段是否正确
2. 验证 `level` 字段值是否为 1-5

## 📝 注意事项

1. **代码格式**: 数据库中的 `code` 字段为 12 位数字字符串
2. **级联关系**: 通过 `pcode` 字段实现父子关系
3. **性能优化**: 前端实现了数据缓存，避免重复请求
4. **搜索功能**: 支持模糊搜索行政区名称
5. **数据量**: 村级数据量大（60万+），加载可能需要时间
