# 行政区级联选择器使用说明

## 📋 功能概述

实现了省-市-区三级级联选择器，用户可以逐级选择行政区（例如：湖南省 → 衡阳市 → 雁峰区），选择完成后自动分析该区域的 `risk_shange_2000.tif` 栅格数据，统计各风险等级的面积与占比。

## 🎯 核心功能

### 1. 三级级联选择
- **省级**: 湖南省
- **市级**: 衡阳市、益阳市等
- **区级**: 雁峰区、石鼓区、蒸湘区、资阳区、赫山区等

### 2. 自动联动分析
```
选择行政区（例如：湖南省 > 衡阳市 > 雁峰区）
    ↓
获取该区域的边界框 (bounds)
    ↓
地图高亮显示该区域
    ↓
调用后端 API 分析该区域的栅格数据
    ↓
统计图表自动更新
    ↓
显示该区域各风险等级的面积和占比
```

## 📍 界面位置

- **位置**: 页面顶部居中
- **样式**: 深色半透明背景 + 青色边框
- **交互**: 悬停时边框发光增强

## 🔧 使用方法

### 基本使用

1. **打开应用**
2. **点击顶部级联选择器**
3. **选择省份** - 例如"湖南省"
4. **选择城市** - 例如"衡阳市"
5. **选择区县** - 例如"雁峰区"
6. **自动触发**:
   - 地图飞到该区域并高亮显示
   - 如果分析面板已打开，自动更新统计数据
   - 区域名称显示为"湖南省 衡阳市 雁峰区"

### 清除选择

- 点击选择器右侧的 ✕ 按钮
- 清除后恢复全图分析

## 📊 数据结构

### 行政区数据格式

```javascript
{
  code: '430702',           // 行政区代码
  name: '雁峰区',           // 行政区名称
  bounds: {                 // 边界框
    minLon: 112.57,         // 最小经度
    maxLon: 112.65,         // 最大经度
    minLat: 26.88,          // 最小纬度
    maxLat: 26.93           // 最大纬度
  },
  children: [...]           // 子级行政区（可选）
}
```

### 级联选择器值格式

```javascript
// 选中"湖南省 > 衡阳市 > 雁峰区"时
selectedDistrictPath.value = ['430000', '430700', '430702']
```

### 完整行政区信息

```javascript
{
  code: '430702',
  name: '雁峰区',
  fullName: '湖南省 衡阳市 雁峰区',  // 完整路径名称
  level: 'county',                   // 级别: province/city/county
  bounds: { minLon, maxLon, minLat, maxLat }
}
```

### 分析接口

```javascript

    minLat: 26.88,
    maxLat: 26.93
  },
```

## ⚠️ 注意事项

### 1. 边界框数据

- 每个最底层的行政区（区/县）**必须**包含 `bounds` 数据
- 边界框格式: `{ minLon, maxLon, minLat, maxLat }`
- 坐标系统: WGS84 (EPSG:4326)

### 2. 级联选择器配置

```javascript
const cascaderProps = {
  value: 'code',           // 使用 code 作为值
  label: 'name',           // 使用 name 作为显示文本
  children: 'children',    // 子节点字段名
  expandTrigger: 'hover',  // 悬停展开
  checkStrictly: false     // 只能选择最后一级
};
```

### 3. 数据来源

当前使用的是硬编码的示例数据。实际应用中应该：
- 从后端 API 获取完整的行政区数据
- 包含所有省市区的完整层级
- 包含准确的边界框坐标

### 4. 性能优化

- 使用边界框而不是多边形，减少数据量
- 级联选择器支持懒加载（可选）
- 缓存已加载的行政区数据

## 🚀 扩展功能

### 1. 从后端加载行政区数据

```javascript
import { onMounted } from 'vue';

onMounted(async () => {
  try {
    const response = await fetch('/api/districts');
    const data = await response.json();
    districtOptions.value = data;
  } catch (error) {
    console.error('加载行政区数据失败:', error);
  }
});
```

### 2. 懒加载子级行政区

```javascript
const cascaderProps = {
  value: 'code',
  label: 'name',
  children: 'children',
  lazy: true,
  lazyLoad: async (node, resolve) => {
    const { level, value } = node;
    
    // 加载子级数据
    const response = await fetch(`/api/districts/${value}/children`);
    const children = await response.json();
    
    resolve(children);
  }
};
```

### 3. 支持多选

```javascript
<el-cascader
  v-model="selectedDistrictPaths"
  :options="districtOptions"
  :props="{ ...cascaderProps, multiple: true }"
  @change="handleMultipleDistrictChange"
/>
```

### 4. 添加搜索功能

```javascript
<el-cascader
  v-model="selectedDistrictPath"
  :options="districtOptions"
  :props="cascaderProps"
  filterable
  :filter-method="filterDistrict"
/>
```
