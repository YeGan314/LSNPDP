# 天气功能使用说明

## 功能概述

在大屏左上角实时显示当前选中区域的天气信息，包括：
- **温度**：实时气温（℃）
- **湿度**：空气湿度（%）
- **风向**：风向和风速（km/h）

## 功能特性

### 1. 默认天气
- 页面加载时，自动显示**武汉市**的实时天气
- 如果网络请求失败，显示占位符 `--`

### 2. 区域联动
当用户通过右上角行政区选择器切换城市时，天气数据会自动更新：

- **选择城市**：显示该城市的实时天气
  - 示例：选择"湖南省 > 岳阳市" → 显示岳阳市天气
  
- **仅选择省份**：显示省会城市天气
  - 示例：选择"湖北省" → 显示武汉市天气
  - 示例：选择"湖南省" → 显示长沙市天气

### 3. 数据来源
- **API提供商**：高德地图天气API
- **数据类型**：实时天气（base）
- **API文档**：https://lbs.amap.com/api/webservice/guide/api/weatherinfo

### API方法

#### `getWeather(city, extensions)`
获取指定城市的天气信息

**参数：**
- `city`：城市名称或adcode（如：武汉、420100）
- `extensions`：`base`=实况天气，`all`=预报天气

**返回：**
```javascript
{
  success: true,
  province: "湖北",
  city: "武汉",
  weather: "晴",
  temperature: "16",
  humidity: "65",
  winddirection: "东北风",
  windpower: "≤3"
}
```

#### `getWeatherByAdcode(adcode)`
通过行政区代码查询天气（推荐）

#### `getWeatherByCity(cityName)`
通过城市名称查询天气

#### `formatWind(direction, power)`
格式化风向风力为 "东北风 7 km/h" 格式

## 使用示例

### 组件中使用
```vue
<script setup>
import { ref, onMounted } from 'vue';
import { getWeatherByCity } from '@/api/weather';

const weatherData = ref({
  temperature: '--',
  humidity: '--',
  wind: '--'
});

onMounted(async () => {
  const result = await getWeatherByCity('武汉');
  if (result.success) {
    weatherData.value = {
      temperature: `${result.temperature}℃`,
      humidity: `${result.humidity}%`,
      wind: formatWind(result.winddirection, result.windpower)
    };
  }
});
</script>

<template>
  <div>
    <p>温度：{{ weatherData.temperature }}</p>
    <p>湿度：{{ weatherData.humidity }}</p>
    <p>风向：{{ weatherData.wind }}</p>
  </div>
</template>
```

### 行政区变化联动
```javascript
watch(currentRegion, (newRegion) => {
  if (newRegion.city) {
    const cityName = newRegion.city.name;
    const cityAdcode = newRegion.city.code.substring(0, 6);
    loadWeather(cityName, cityAdcode);
  }
}, { deep: true });
```

### 错误处理
- 网络请求失败时，天气数据显示为 `--`
- 控制台会打印详细错误日志（❌ 标记）

### 跨域问题
- 高德API支持跨域请求（CORS）
- 无需配置代理

## 调试建议

### 1. 查看天气请求日志
打开浏览器控制台（F12），查看以下日志：
- `🌍 加载默认天气: 武汉` - 页面加载
- `🌤️ 获取天气数据: 武汉, null` - 天气请求
- `✅ 天气数据更新成功:` - 天气更新成功
- `🗺️ 行政区变化，更新天气:` - 区域切换

### 2. 网络请求检查
在开发者工具 Network 面板中：
- 筛选 XHR 请求
- 查找 `weatherInfo` 接口
- 检查请求参数和响应数据

### 3. 常见问题
**问题：天气显示 `--`**
- 检查网络连接
- 查看控制台错误信息
- 确认API Key是否有效

**问题：切换城市后天气不更新**
- 检查 `currentRegion` 是否正确更新
- 查看 `watch` 监听器是否触发
- 确认城市名称或adcode格式正确

### 3. 添加天气预报
```javascript

// 可获取未来3天天气预报
```

### 4. 添加缓存机制
```javascript
const weatherCache = new Map();

const loadWeather = async (cityName, adcode) => {
  const cacheKey = adcode || cityName;
  const cached = weatherCache.get(cacheKey);
  
  // 缓存5分钟
  if (cached && Date.now() - cached.time < 5 * 60 * 1000) {
    weatherData.value = cached.data;
    return;
  }
  
  // 请求新数据...
};
```
