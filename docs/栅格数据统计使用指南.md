# 栅格数据统计使用指南

## 概述

本指南介绍如何统计WMS栅格服务（如`risk_2000`）中各个级别值的占比。

## 统计方法

### 方法1: WMS GetFeatureInfo 采样统计（推荐）

**原理**: 在栅格范围内进行网格采样，通过WMS GetFeatureInfo请求获取每个采样点的像素值，然后统计各级别值的分布。

**优点**:
- ✅ 不需要访问原始栅格文件
- ✅ 适用于任何WMS服务
- ✅ 可以自定义采样范围和密度
- ✅ 实时统计，无需预处理

**缺点**:
- ⚠️ 采样点数量越多，统计时间越长
- ⚠️ 是近似统计，不是精确统计
- ⚠️ 需要GeoServer支持GetFeatureInfo请求

**适用场景**: 
- 快速了解栅格数据分布
- 对精度要求不高的场景
- 无法访问原始栅格文件

### 方法2: GeoServer REST API

**原理**: 通过GeoServer的REST API获取栅格图层的元数据信息。

**优点**:
- ✅ 获取图层完整信息
- ✅ 请求速度快

**缺点**:
- ❌ 默认不提供像素值统计
- ❌ 需要GeoServer额外配置或插件

**适用场景**: 
- 获取图层基本信息
- 配合其他统计方法使用

### 方法3: 直接访问原始栅格数据（最精确）

**原理**: 使用GDAL库直接读取GeoTIFF等栅格文件，遍历所有像素值进行统计。

**优点**:
- ✅ 100%精确统计
- ✅ 可以获取详细的统计信息（最大值、最小值、均值等）

**缺点**:
- ❌ 需要访问服务器文件系统
- ❌ 需要后端支持
- ❌ 大文件处理较慢

**适用场景**: 
- 需要精确统计
- 有服务器访问权限
- 离线分析

### 2. 直接使用服务

```javascript
import { rasterStatsService } from '@/services/rasterStatsService';
import { getViewer } from './js/threeCesium';

// 方法1: WMS采样统计
async function statisticsRisk2000() {
  const viewer = getViewer();
  
  // 定义统计范围
  const bounds = {
    west: 112.87,   // 西经度
    south: 28.84,   // 南纬度
    east: 113.02,   // 东经度
    north: 28.98    // 北纬度
  };
  
  // 开始统计（50x50 = 2500个采样点）
  const result = await rasterStatsService.sampleRasterValues(
    viewer,
    'risk_2000',  // 图层名称
    bounds,
    50            // 采样密度
  );
  
  if (result.success) {
    console.log('统计结果:', result.statistics);
    
    // 输出示例:
    // [
    //   { value: 0, count: 1200, percentage: 48.0, percentageText: '48.00%' },
    //   { value: 1, count: 800, percentage: 32.0, percentageText: '32.00%' },
    //   { value: 2, count: 500, percentage: 20.0, percentageText: '20.00%' }
    // ]
    
    // 导出CSV
    rasterStatsService.exportToCSV(result.statistics, 'risk_2000_stats.csv');
  }
}

// 方法2: REST API获取图层信息
async function getLayerInfo() {
  const result = await rasterStatsService.getRasterStatsFromGeoServer('risk_2000');
  
  if (result.success) {
    console.log('图层信息:', result.layerInfo);
  }
}
```

## 配置说明

### 采样密度选择

| 密度 | 采样点数 | 统计时间 | 精度 | 适用场景 |
|------|---------|---------|------|---------|
| 低 (20x20) | 400 | ~10秒 | 较低 | 快速预览 |
| 中 (50x50) | 2,500 | ~1分钟 | 中等 | 常规统计 |
| 高 (100x100) | 10,000 | ~4分钟 | 较高 | 精确统计 |
| 极高 (200x200) | 40,000 | ~15分钟 | 很高 | 科研分析 |

### 统计范围选择

**当前视野**: 自动获取Cesium当前相机视野范围
- 优点: 方便快捷
- 缺点: 范围可能不规则

**自定义范围**: 手动输入经纬度边界
- 优点: 精确控制统计区域
- 缺点: 需要知道准确的坐标

## GeoServer配置

### 1. 确保GetFeatureInfo可用

编辑GeoServer图层配置，确保启用了GetFeatureInfo功能：

```xml
<!-- 在图层的WMS配置中 -->
<queryable>true</queryable>
```

### 2. 配置CORS（跨域）

如果前端和GeoServer不在同一域名，需要配置CORS：

在 `web.xml` 中添加：

```xml
<filter>
  <filter-name>CorsFilter</filter-name>
  <filter-class>org.apache.catalina.filters.CorsFilter</filter-class>
  <init-param>
    <param-name>cors.allowed.origins</param-name>
    <param-value>*</param-value>
  </init-param>
  <init-param>
    <param-name>cors.allowed.methods</param-name>
    <param-value>GET,POST,HEAD,OPTIONS,PUT</param-value>
  </init-param>
</filter>
<filter-mapping>
  <filter-name>CorsFilter</filter-name>
  <url-pattern>/*</url-pattern>
</filter-mapping>
```

### 3. 测试GetFeatureInfo请求

在浏览器中测试以下URL（替换为实际参数）：

## 性能优化

### 1. 批量请求优化

```javascript
// 使用Promise.all并行请求，但限制并发数
async function sampleWithConcurrency(points, concurrency = 10) {
  const results = [];
  
  for (let i = 0; i < points.length; i += concurrency) {
    const batch = points.slice(i, i + concurrency);
    const batchResults = await Promise.all(
      batch.map(point => getPixelValue(point.lon, point.lat))
    );
    results.push(...batchResults);
  }
  
  return results;
}
```

### 2. 缓存结果

```javascript
// 缓存统计结果，避免重复计算
const statsCache = new Map();

async function getCachedStats(layerName, bounds, sampleSize) {
  const key = `${layerName}_${JSON.stringify(bounds)}_${sampleSize}`;
  
  if (statsCache.has(key)) {
    console.log('使用缓存结果');
    return statsCache.get(key);
  }
  
  const result = await rasterStatsService.sampleRasterValues(...);
  statsCache.set(key, result);
  
  return result;
}
```

## 常见问题

### Q1: GetFeatureInfo返回空结果？

**可能原因**:
1. 图层未设置为可查询（queryable=false）
2. 坐标超出图层范围
3. 栅格数据在该位置为NoData值

**解决方案**:
- 检查GeoServer图层配置
- 验证坐标是否在图层范围内
- 查看GeoServer日志

### Q2: 统计速度太慢？

**优化方案**:
1. 降低采样密度（如从100x100降到50x50）
2. 缩小统计范围
3. 使用后端批量处理
4. 启用结果缓存

### Q3: 统计结果不准确？

**原因分析**:
- 采样统计是近似方法，不是精确统计
- 采样点数量不足

**改进方法**:
1. 增加采样密度
2. 使用分层采样（重要区域密集采样）
3. 使用后端GDAL进行精确统计

### Q4: CORS跨域错误？

**解决方案**:
1. 配置GeoServer CORS
2. 使用代理服务器
3. 在开发环境使用Vue代理：

```javascript
// vue.config.js
module.exports = {
  devServer: {
    proxy: {
      '/geoserver': {
        target: 'http://8.140.227.53:8080',
        changeOrigin: true
      }
    }
  }
}
```

### 3. 自定义统计指标

```javascript
// 计算额外的统计指标
function calculateAdvancedStats(statistics) {
  const values = statistics.map(s => s.value);
  const counts = statistics.map(s => s.count);
  const total = counts.reduce((a, b) => a + b, 0);
  
  // 加权平均值
  const mean = values.reduce((sum, val, i) => 
    sum + val * counts[i], 0
  ) / total;
  
  // 众数（出现最多的值）
  const mode = statistics.reduce((max, s) => 
    s.count > max.count ? s : max
  ).value;
  
  // 中位数
  const sortedValues = [...values].sort((a, b) => a - b);
  const median = sortedValues[Math.floor(sortedValues.length / 2)];
  
  return { mean, mode, median };
}
```
