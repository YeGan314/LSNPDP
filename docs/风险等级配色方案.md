# 风险等级配色方案

## 📊 配色标准

系统中所有风险等级相关的可视化组件（WMS图例、统计图表等）统一使用以下配色方案：

| 风险等级 | 颜色值 | 颜色预览 | 风险描述 | 应用场景 |
|---------|--------|---------|---------|---------|
| **1级** | `#22c55e` | 🟢 绿色 | 低风险 | WMS图例、柱状图、饼图、表格徽章 |
| **2级** | `#84cc16` | 🟢 浅绿色 | 较低风险 | WMS图例、柱状图、饼图、表格徽章 |
| **3级** | `#eab308` | 🟡 黄色 | 中等风险 | WMS图例、柱状图、饼图、表格徽章 |
| **4级** | `#f97316` | 🟠 橙色 | 较高风险 | WMS图例、柱状图、饼图、表格徽章 |
| **5级** | `#ef4444` | 🔴 红色 | 高风险 | WMS图例、柱状图、饼图、表格徽章 |

## 🎨 配色原理

### 渐变设计
- **起点**：1级使用绿色（`#22c55e`），表示安全、低风险
- **中点**：3级使用黄色（`#eab308`），表示警示、中等风险
- **终点**：5级使用红色（`#ef4444`），表示危险、高风险

### 色彩心理学
- **绿色系（1-2级）**：代表安全、健康、低风险
- **黄色（3级）**：代表警告、注意、中等风险
- **橙红色系（4-5级）**：代表危险、紧急、高风险

## 💻 使用方法

### 1. 导入配色函数

```javascript
import { getRiskLevelColor } from './riskLevelColors';
```

### 2. 获取单个等级颜色

```javascript
const color = getRiskLevelColor(1); // 返回 '#22c55e'
```

### 3. 在组件中使用

```javascript
// Vue组件中
methods: {
  getLevelColor(level) {
    return getRiskLevelColor(level);
  }
}
```

### 4. 在模板中使用

```vue
<div :style="{ backgroundColor: getLevelColor(item.level) }">
  等级 {{ item.level }}
</div>
```

## 🎯 配色一致性检查清单

在添加新的风险等级相关功能时，请确保：

- [ ] 使用 `riskLevelColors.js` 中的配色函数
- [ ] 不要硬编码颜色值
- [ ] 1级必须是绿色系
- [ ] 5级必须是红色系
- [ ] 中间等级按渐变过渡
- [ ] 所有图表、图例、徽章使用相同配色

## 🔄 配色更新流程

如需修改配色方案：

1. **修改配置文件**
   ```javascript
   // src/views/big-screen/compoments/raster-analysis/riskLevelColors.js
   export const RISK_LEVEL_COLORS = {
     1: '#新颜色值',
     // ...
   };
   ```

2. **无需修改组件**
   - 所有使用 `getRiskLevelColor()` 的组件会自动更新

3. **测试验证**
   - 检查WMS图例
   - 检查分析报告柱状图
   - 检查分析报告饼图
   - 检查数据表格徽章

## ⚠️ 注意事项

1. **不要硬编码颜色**
   ```javascript
   // ❌ 错误做法
   const color = '#22c55e';
   
   // ✅ 正确做法
   import { getRiskLevelColor } from './riskLevelColors';
   const color = getRiskLevelColor(1);
   ```

2. **保持一致性**
   - 所有风险等级相关的可视化必须使用相同配色
   - 不要在不同组件中使用不同的颜色方案

3. **渐变方向**
   - 必须从绿色（低风险）到红色（高风险）
   - 不要反转渐变方向
