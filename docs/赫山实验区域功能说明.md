# 赫山实验区域功能说明

## 📋 功能概述

在"地理数据"面板的"渠道分布"后面添加了"赫山实验区域"勾选按钮，用于在地图上显示/隐藏 GeoServer 服务提供的行政区划缓冲区数据。

**文件**: `src/views/big-screen/compoments/yewu2/Right/right-page.vue`

**UI 位置**: 
```
右侧面板
  └─ 地理数据
      ├─ □ bigmap

      ├─ □ 高德街景
      ├─ ☑ 流域分布

      └─ □ 赫山实验区域  ← 新增
```

## 🔧 技术实现

### 1. 数据配置

```javascript
const List3 = [
  // ... 其他选项
  {
    value: "hsqBuffer",
    text: "赫山实验区域",
    check: false,  // 默认不勾选
  },
];
```

### 2. WMS 服务配置

```javascript
// 图层配置
{
  url: "/geoserver/YG/wms",           // 使用代理地址
  layers: "YG:HSQ_XZQ_MAP_BUFFER",    // GeoServer 图层名称
  parameters: {
    transparent: true,                 // 透明背景
    format: "image/png",              // PNG 格式
    version: "1.1.0",                 // WMS 版本
    styles: "",                       // 默认样式
  },
  alpha: 0.8,                         // 80% 透明度
  brightness: 1.0,                    // 正常亮度
  contrast: 1.0,                      // 正常对比度
}
```

### 3. 核心逻辑

```javascript
// 存储图层引用
let hsqBufferLayer = null;

// 切换图层显示/隐藏
const checkedChaneOther = () => {
  List3.forEach((item) => {
    if (item.value === "hsqBuffer") {
      if (item.check) {
        // 勾选 - 加载或显示图层
        if (!hsqBufferLayer) {
          hsqBufferLayer = initWMSService({...config});
        } else {
          hsqBufferLayer.show = true;
        }
      } else {
        // 取消勾选 - 隐藏图层
        if (hsqBufferLayer) {
          hsqBufferLayer.show = false;
        }
      }
    }
  });
};

// 组件卸载时清理图层
onUnmounted(() => {
  if (hsqBufferLayer) {
    viewer.imageryLayers.remove(hsqBufferLayer);
    hsqBufferLayer = null;
  }
});
```

## 💡 功能特点

### 1. 智能加载
- ✅ **首次勾选**：加载 WMS 图层
- ✅ **再次勾选**：直接显示已加载的图层（不重复加载）
- ✅ **性能优化**：避免重复请求

### 2. 状态管理
- ✅ **显示/隐藏切换**：通过 `show` 属性控制
- ✅ **图层持久化**：图层对象在组件生命周期内保持
- ✅ **自动清理**：组件卸载时自动移除图层

### 3. 用户体验
- ✅ **即时响应**：勾选后立即显示
- ✅ **视觉反馈**：透明度 80%，不遮挡其他图层
- ✅ **无缝集成**：与其他地理数据选项保持一致的交互方式

## 🎨 样式调整

如需修改图层样式，可以调整以下参数：

```javascript
// 在 checkedChaneOther 函数中修改
hsqBufferLayer = initWMSService({
  // ...
  alpha: 0.5,        // 透明度: 0 (完全透明) ~ 1 (不透明)
  brightness: 1.2,   // 亮度: 0 (最暗) ~ 2 (最亮)
  contrast: 1.5,     // 对比度: 0 (无对比) ~ 2 (高对比)
});

// 或者运行时动态调整
if (hsqBufferLayer) {
  hsqBufferLayer.alpha = 0.6;
  hsqBufferLayer.brightness = 1.1;
  hsqBufferLayer.contrast = 1.2;
}
```

## 🔧 故障排查

### 问题 1: 勾选后图层不显示

**检查步骤：**
1. 打开浏览器控制台（F12）
2. 查看是否有错误信息
3. 检查 WMS 服务是否正常：
   ```javascript
   // 在控制台执行
   fetch('/geoserver/YG/wms?service=WMS&version=1.1.0&request=GetCapabilities')
     .then(r => r.text())
     .then(t => console.log(t));
   ```

**常见原因：**
- ❌ GeoServer 服务未启动
- ❌ 代理配置错误
- ❌ 图层名称不正确
- ❌ 网络问题

### 问题 2: 图层被其他图层遮挡

**解决方案：**
```javascript
// 将图层移到最上层
if (hsqBufferLayer) {
  const viewer = viewerCesium();
  viewer.imageryLayers.raiseToTop(hsqBufferLayer);
}
```

### 问题 3: 图层太透明或太不透明

**调整透明度：**
```javascript
if (hsqBufferLayer) {
  hsqBufferLayer.alpha = 0.9; // 调整到合适的值
}
```

## 📊 技术参数

### WMS 请求示例

实际发送的 GetMap 请求：
```
http://8.140.227.53:8080/geoserver/YG/wms?
  service=WMS&
  version=1.1.0&
  request=GetMap&
  layers=YG:HSQ_XZQ_MAP_BUFFER&
  bbox=112.60,28.49,112.62,28.51&
  width=768&
  height=464&
  srs=EPSG:4326&
  format=image/png&
  transparent=true
```

### 图层信息

- **工作空间**: YG
- **图层名称**: HSQ_XZQ_MAP_BUFFER
- **数据类型**: 矢量（转换为栅格显示）
- **坐标系**: EPSG:4326 (WGS84)
- **格式**: PNG (支持透明)
