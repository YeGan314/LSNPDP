# 行政区选择与统计图联动功能使用说明

## 📋 功能概述

实现了行政区选择器与栅格分析统计图的自动联动功能。当用户在界面上选择不同的行政区（省、市、县）时，右侧分析面板会自动更新显示该区域的统计数据。

## 🎯 核心功能

### 1. 自动联动更新
- 选择行政区后，地图自动高亮显示该区域
- 如果分析面板已打开，自动重新分析并更新统计数据
- 统计图表（柱状图、饼图）实时更新

### 2. 状态管理
```javascript
// 行政区选择相关状态
const selectedDistrict = ref(null);        // 当前选中的行政区
const selectedDistrictLevel = ref('');     // 行政区级别
const selectedDistrictCode = ref('');      // 行政区代码
const districtBoundary = ref(null);        // 区域边界坐标
```

### 3. 监听器机制
```javascript
watch(selectedDistrict, async (newDistrict) => {
  // 1. 更新行政区信息
  // 2. 高亮显示区域
  // 3. 如果分析面板已打开，自动更新数据
});
```

## 🔧 使用方法

### 方式1: 通过行政区选择器（推荐）

```vue
<template>
  <!-- 在工具栏中使用行政区选择器 -->
  <RasterAnalysisToolbar
    @analyze="handleRasterAnalyze"
    @district-change="handleDistrictChange"
  />
</template>

<script setup>
import { ref } from 'vue';

const selectedDistrict = ref(null);

// 处理行政区变化
const handleDistrictChange = (district) => {
  selectedDistrict.value = district;
  // 监听器会自动处理后续逻辑
};
</script>
```

### 方式2: 直接设置选中的行政区

```javascript
import districtDataService from '@/services/districtDataService';

// 获取行政区数据
const district = districtDataService.getDistrictById('heshan');

// 设置选中状态（会触发自动联动）
selectedDistrict.value = district;
```

### 方式3: 通过分析函数手动触发

```javascript
// 分析特定行政区
await handleRasterAnalyze({
  layer: currentLayer,
  district: district  // 传入行政区对象
});

// 分析当前选中的行政区
await handleRasterAnalyze({
  layer: currentLayer
  // district 参数省略，自动使用 selectedDistrict.value
});

// 分析全图
selectedDistrict.value = null;  // 清除选择
await handleRasterAnalyze({
  layer: currentLayer
});
```

## 📝 代码示例

### 完整示例：选择行政区并分析

```vue
<template>
  <div class="analysis-demo">
    <!-- 行政区选择器 -->
    <DistrictSelector
      v-model="selectedDistrictId"
      @change="handleDistrictChange"
    />
    
    <!-- 分析按钮 -->
    <button @click="triggerAnalysis">
      分析当前区域
    </button>
    
    <!-- 分析面板 -->
    <RasterAnalysisPanel
      :visible="analysisVisible"
      :loading="analysisLoading"
      :analysis-data="analysisData"
      :region-name="regionName"
      @close="analysisVisible = false"
    />
  </div>
</template>

<script setup>
import { ref } from 'vue';
import districtDataService from '@/services/districtDataService';

const selectedDistrictId = ref(null);
const selectedDistrict = ref(null);
const analysisVisible = ref(false);
const analysisLoading = ref(false);
const analysisData = ref(null);
const regionName = ref('全图');

// 处理行政区变化
const handleDistrictChange = (district) => {
  console.log('选择行政区:', district);
  selectedDistrict.value = district;
  
  // 如果分析面板已打开，自动更新
  if (analysisVisible.value) {
    triggerAnalysis();
  }
};

// 触发分析
const triggerAnalysis = async () => {
  analysisLoading.value = true;
  analysisVisible.value = true;
  
  try {
    const layer = {
      id: 'risk_shange_2000',
      name: '风险等级图层',
      tifPath: '../geodata/risk_shange_2000.tif'
    };
    
    await handleRasterAnalyze({
      layer,
      district: selectedDistrict.value
    });
  } finally {
    analysisLoading.value = false;
  }
};
</script>
```

## ⚠️ 注意事项

1. **避免循环触发**
   - 监听器中调用 `handleRasterAnalyze` 时，不会再次触发监听器
   - 因为 `selectedDistrict.value` 没有变化

2. **清除选择**
   ```javascript
   // 正确方式
   selectedDistrict.value = null;
   
   // 错误方式（不会触发监听器）
   selectedDistrictId.value = null;
   ```

3. **性能优化**
   - 监听器中有防抖机制，避免频繁触发
   - 只有在分析面板已打开时才自动更新

4. **错误处理**
   ```javascript
   try {
     await handleRasterAnalyze({ layer, district });
   } catch (error) {
     console.error('分析失败:', error);
     // 显示错误提示
   }
   ```
